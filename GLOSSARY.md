# Agent Skills

This context defines the shared language for reusable instructions and delegated
engineering work performed by AI coding agents.

## Language

**Worker Role**:
A named responsibility and constraint set for bounded work delegated from a
primary agent. It includes permitted scope, reserved decisions, and required
evidence.
_Avoid_: Role contract, worker profile

**Project Memory Space**:
A collection of short-term notes shared by projects with the same project name.
Projects that need separate memories use distinct names.
